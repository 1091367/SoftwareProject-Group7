# Backend Design

## Overview
The backend of the Smart Food-Waste Redistribution Platform will manage users, surplus food records, recipient matching, pickup information, and redistribution activities.

## Technologies
- Node.js
- Express
- PostgreSQL
- REST API

## Main Backend Functions
- User authentication and role management
- Manage surplus food records
- Store and retrieve business and charity information
- Support recipient matching
- Manage pickup and collection information
- Store redistribution transaction records
- Provide data for reporting and system integration

## Database
PostgreSQL will be used to store users, food surplus records, transactions, pickup information, and other system data.

## Security
Access to backend functions will depend on user roles. Authentication will be used to protect accounts and prevent unauthorized access.
